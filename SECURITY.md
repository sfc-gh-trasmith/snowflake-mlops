# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it responsibly.

**Do NOT open a public GitHub issue for security vulnerabilities.**

Instead, please report vulnerabilities via one of the following channels:

- **Email:** [security@snowflake.com](mailto:security@snowflake.com)
- **HackerOne:** [https://hackerone.com/snowflake](https://hackerone.com/snowflake)

Please include:
- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if any)

## Response Timeline

We aim to acknowledge reports within 3 business days and provide a resolution timeline within 10 business days.

## Scope

This policy applies to the code in this repository. For vulnerabilities in Snowflake's platform services, please use the HackerOne program linked above.
